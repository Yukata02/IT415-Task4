# IT415 Task 4 — Git Merge Conflict Exercise

Campus Help Desk page used to practice branching, conflicting edits, and conflict resolution on GitHub.

## Scenario

Two officers update the same status line at the same time:

- `helpdesk-alex` posts that walk-ins are welcome until 5:00 PM.
- `helpdesk-jordan` posts that the queue pauses at 3:00 PM for appointments only.

Merging Alex first succeeds. Merging Jordan after that creates a conflict on that one line. You resolve it by combining both rules.

## Deliverables to capture while you work

1. Screenshot of conflict markers in `index.html`
2. Final corrected file code
3. Screenshot of clean `git status`
4. Short reflection: what caused the conflict?
5. GitHub repository link after the resolved merge is pushed
